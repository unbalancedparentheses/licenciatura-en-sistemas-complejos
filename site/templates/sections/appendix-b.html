Marco de evaluación por materia

Evaluation Framework by Course

Evaluación primaria y secundaria de cada asignatura y de cada Taller Integrador, ordenadas por cuatrimestre. WE: examen escrito presencial con problemas inéditos. LC: sesión en vivo con preguntas en tiempo real. OD: defensa oral. PD: defensa pública ante panel. TP: trabajo práctico o proyecto. WP: portfolio escrito con historia de revisiones. La tabla se genera a partir de los mismos datos que las fichas de las materias.

Primary and secondary evaluation for each course and each Integrative Taller, ordered by cuatrimestre. WE: in-person written exam with unseen problems. LC: live session with real-time questioning. OD: oral defense. PD: public defense before a panel. TP: practical work or project. WP: written portfolio with revision history. The table is generated from the same data as the course descriptions.
